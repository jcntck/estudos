# Estudos

Repositório de artefatos de estudos: implementações, experimentos, testes e anotações produzidos durante o aprendizado de conceitos e técnicas de desenvolvimento de software.

Cada pasta reúne um tema e possui um README com o contexto do estudo e orientações para explorar seus artefatos.

## Estudos disponíveis

| Pasta | O que representa |
| --- | --- |
| [erathostenes](erathostenes/readme.md) | Estudo do Crivo de Eratóstenes em Go, com duas implementações para encontrar números primos, testes de correção e benchmarks para comparar desempenho. |

## Como explorar

Clone o repositório e acesse a pasta do tema que deseja estudar:

```sh
git clone git@github.com:jcntck/estudos.git
cd estudos
```

Consulte o README de cada pasta para conhecer os requisitos e os comandos específicos daquele estudo.
